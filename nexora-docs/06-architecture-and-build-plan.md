## Confirmed decisions

- Keep V1 practical and simple; avoid premature complexity.
- Do not begin writing application code until the user explicitly says implementation is ready.
- Avoid microservices, Kubernetes, complex event infrastructure, large numbers of AI agents, multi-agent debates, and self-modifying strategies for V1.
